# ADR 0005: Permission-based RBAC scoped by branch

- Status: Accepted
- Date: 2026-10-26
- Score: 98/100 (rubric: docs/project-plan.md §3)

## Context
Roles differ per branch (e.g. manager in Kish only); the owner must create roles without a deploy.

## Options considered
- Hard-coded roles in code
- **Chosen:** see Decision

## Decision
Permissions `resource:action`; roles are sets of permissions; `user_roles.branch_id` (null = all). Checked in the service layer via `requirePermission()`.

## Consequences
Flexible and auditable. Needs seeding of default roles and tests per permission.

## Revisit when
Permission count grows beyond ~150 — then group into features.
