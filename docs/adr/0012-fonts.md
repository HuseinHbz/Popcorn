# ADR 0012: Typography: Peyda headlines, Vazirmatn body

- Status: Accepted
- Date: 2026-10-26
- Score: 98/100 (rubric: docs/project-plan.md §3)

## Context

Luxury feel in Persian requires a refined display face; budget for a commercial license was approved.

## Options considered

- Estedad (OFL) for headlines
- Google-hosted fonts
- **Chosen:** see Decision

## Decision

Peyda (commercial web license) for Persian headlines, Vazirmatn (OFL) body, Shippori Mincho (OFL) Latin display; all self-hosted WOFF2 with subsetting.

## Consequences

License cost; must confirm web license covers all production domains.

## Revisit when

Brand guideline of an existing logo conflicts with Peyda.
