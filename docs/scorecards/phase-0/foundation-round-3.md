### Deductions in detail

- **P2 (−1.0), the Lighthouse gate asserts the best of five runs, not the median.** `lighthouserc.json:12-21` uses `"aggregationMethod": "median-run"` on `categories:*`. In `@lhci/utils` 0.15.1, category assertions are evaluated over **all** runs (`src/assertions.js:305` passes `lhrs`, not `medianLhrs`), and for any method other than `"median"` a `minScore` assertion takes `Math.max(...values)` (`:56-67`). Proof on this reviewer's sample 1: medians 94 (`/fa`) and 93 (`/en`), yet `pnpm lhci` exited 0; `lhci assert` with `"median"` fails both; with `median-run` at 0.97 it reports `/en` "found: 0.96" — its best run. So AC6 (`docs/stories/platform-foundation.md:21`, "median of 5"), the DoD and the phase-00 gate are enforced only as "one run in five ≥ 95". Under these semantics a sample such as 80, 88, 90, 92, 96 (median 90) passes. The round-2 review also read `median-run` as a median.
- **P3 (−0.25), Shippori Mincho is downloaded where it renders nothing, and it is the late-loaded first face of the LCP element.** No `@font-face` declares a `unicode-range` (`src/shared/ui/fonts/index.ts:18-51`; built CSS confirms). The heading stack starts with Shippori (`src/app/globals.css:22`, `page.tsx:20`, `not-found.tsx:11`), so the browser fetches its 28 KB file on `/fa` too: 10 of 10 `/fa` runs requested it. It is not preloaded, and the `h1` is the LCP element on both locales (LCP 1.4–3.0 s; FCP ≈ 1.1 s). The justification at `fonts/index.ts:40` and ADR 0017:39-40 ("not preloaded, because Persian pages do not use its glyphs") misses the download. The margin is thin: sample 1 medians 94/93, sample 2 97/96.
- **TS1 (−0.25), the new freshness gates trust network JSON with `as` and fail open on a shape change.** `scripts/check-node-version.ts:33` casts nodejs.org's index to `NodeRelease[]`; a list whose entries lack a boolean `security`, or an empty list, filters to `[]` and exits 0. `scripts/check-package-manager.ts:32` casts the advisory response; `{}` is both the "clean" answer and what an ignored request looks like. The round-2 note asked for external JSON to be validated once Zod landed; Zod has landed and two more unchecked casts were added, this time in security gates.
- **L1 (−0.25), token bypasses remain in TS/TSX.** Probes that lint clean: `style={{ 'color': 'red' }}` (string key), ``style={{ color: `red` }}`` (template literal), `style={{ border: '1px solid red' }}` and `style={{ boxShadow: '0 0 4px black' }}` (shorthands; the CSS checker does flag these), `<circle fill='red' />` (JSX presentation attribute), `className='[color:red]'` (Tailwind arbitrary property), and `style={{ padding: '13px', fontFamily: 'Arial', borderRadius: 3 }}`. The comment at `eslint.config.mjs:8-10` claims tokens are enforced for colour, spacing, radius and font; only colour keys and `x-[…]` arbitrary values are.
- **T3 (−0.25), AC4's "JSX text cannot be a literal" has a one-character bypass.** `react/jsx-no-literals` is configured without `noStrings` (`eslint.config.mjs:205`), so `<p>{'Hello world'}</p>` lints clean (probe), as does `aria-label={ok ? 'Yes' : 'No'}` (the selectors at `:39-49` stop at a direct `Literal`/`TemplateLiteral` child) and `<input type='submit' value='Send order' />`. The fixture (`tests/fixtures/src/shared/ui/literal-text.tsx`) only covers bare JSX text.
- **T4 (−0.25), AC9 still has a hole on `main`.** `cancel-in-progress` is now off on `main` (`.github/workflows/ci.yml:15`), but the group is still per ref (`:13`). GitHub keeps at most one pending run per concurrency group and cancels the older pending run when a newer one queues. With three quick pushes to `main`, the middle push's run is cancelled, and its commits are never linted (the next run lints only `BEFORE..HEAD` of its own push, `:47-48`). The comment at `:14` ("Never cancel on main") is therefore not true.
- **T5 (−0.25), two AC clauses have no test.** AC10 (`platform-foundation.md:25`) says Postgres **and** Redis reject wrong **or** missing passwords. CI tests Postgres with a wrong password only (`ci.yml:160-163`) and Redis with a missing password only (`:170-171`). AC18 (`:33`) says the formatters are covered "including … amounts beyond 2^53", but `formatToman` is never called with one (`src/shared/lib/money.test.ts:20-32`); only `irrToToman` is. A regression to `Number(...)` inside `formatToman` would pass every test.
- **S4 (−0.25), a missing `APP_ENV` silently selects the permissive mode.** `src/shared/config/env.ts:10` defaults `APP_ENV` to `development`, which disables the `change-me` check. The comment on `:9` says the deploy sets it explicitly, but nothing requires that: a production deploy that forgets the variable starts with placeholder secrets. `.env.example:22` already sets it, so requiring it costs nothing. The unit test `env.test.ts:25-27` locks in the default.
- **A1 (−0.25), the purity rule still has trivial bypasses.** Round-2 fix 4 asked for `indexedDB` and `caches` in `IMPURE_GLOBALS`; they are missing (`eslint.config.mjs:138-157`; probes `indexedDB.open('x')` and `caches.open('x')` in `domain/` lint clean). The clock ban covers `Date.now()` and argument-less `new Date()` (`:53-63`) but not `Date()` (a function call that returns the current time), `Date['now']()`, `const D = Date; D.now()`, or `new Intl.DateTimeFormat('fa').format()` with no argument (all probed clean). `queueMicrotask` and `setImmediate` are also allowed.
- **A3 (−0.25), the locale list and the fallback rule are each written twice.** `src/shared/lib/locale.ts:2` re-declares `'fa' | 'en'` and says only in a comment that it "mirrors" `routing.locales` (`src/shared/i18n/routing.ts:5-6`); nothing fails if they diverge. The fallback `hasLocale(...) ? requested : routing.defaultLocale` is duplicated in `src/app/[locale]/layout.tsx:23` and `src/shared/i18n/request.ts:11`. The rubric's full-score condition is "no duplication".
- **D1 (−0.5), round-1 D-16 is still open.** `c2d2e84 build: …` still carries the 356-line Prettier reformat of `docs/project-plan.md`. It needs the product owner's approval for a history rewrite; the defect remains in the deliverable.
