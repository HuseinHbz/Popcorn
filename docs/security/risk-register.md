# Security risk register

Accepted risks with an owner, a reason and an expiry. An expired entry fails review until it is
re-justified or fixed. The CI audit gate (`pnpm audit --audit-level=high`) ignores exactly the
advisories listed here via `pnpm.auditConfig.ignoreGhsas` in `package.json`; a second CI gate
requires zero High/Critical in production dependencies with no exceptions, and CI fails when a
"Review by" date has passed (`scripts/check-risk-register.ts`).
