# فازبندی اجرا با Claude Code

هر فاز یک فایل است و هر فاز به چند **PR** کوچک (حداکثر ~۴۰۰ خط) تقسیم شده است. Claude Code هر بار فقط **یک PR** را انجام می‌دهد، آن را از گیت ۹۸ عبور می‌دهد و بعد سراغ PR بعدی می‌رود.

## نحوه اجرا

```bash
cd popcorn
claude
> /phase 00          # اولین PR تیک‌نخورده فاز ۰ را اجرا می‌کند
> /review            # بازبینی مستقل در Session جدید (بعد از /clear یا ترمینال تازه)
```

چرخه هر PR:

1. `/phase NN` ← Claude Code فایل فاز را می‌خواند، Story می‌نویسد، در Plan mode برنامه می‌دهد
2. شما برنامه را تأیید می‌کنید
3. پیاده‌سازی Test-first و اجرای `pnpm verify`
4. Session جدید ← `/review` ← Scorecard در `docs/scorecards/`
5. نمره ≥ ۹۸ ← Merge و تیک زدن PR در فایل فاز؛ زیر ۹۸ ← اصلاح موارد کسرشده

## قانون توقف

اگر پیش‌نیاز یک PR از طرف رستوران نرسیده باشد، Claude Code آن PR را شروع نمی‌کند، مورد را در بخش «Blocked» فایل فاز ثبت می‌کند و سراغ PR بعدی بدون وابستگی می‌رود.
