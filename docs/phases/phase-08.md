# فاز ۸ — بلاگ و Sync سپیدز/راهکاران (هفته ۱۴ و ۱۵)

**هدف:** بلاگ دوزبانه و همگام‌سازی با سپیدز (منو و سفارش) و راهکاران (اسناد فروش).

**پیش‌نیاز:** مستند API و محیط تست سپیدز و راهکاران، تصمیم مرجع اصلی داده (ADR 0011 باید Accepted شود).

**قانون:** اگر ADR 0011 تا پایان هفته ۱۳ Accepted نشود، PRهای 8.2 تا 8.4 به نسخه v2.1 منتقل می‌شوند و انتشار v2.0.0 به آن‌ها وابسته نمی‌ماند.

**گیت فاز:** هیچ سفارشی در قطعی سیستم مقصد گم یا تکراری نشود (تست با قطع شبیه‌سازی‌شده).

- [ ] **PR 8.2 — زیرساخت Sync**
