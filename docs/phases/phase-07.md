# فاز ۷ — باشگاه مشتریان و تحلیل رفتار (هفته ۱۲ و ۱۳)

**هدف:** باشگاه کامل با پروفایل ۳۶۰، امتیاز، کمپین و تحلیل خرید و رفتار.

**پیش‌نیاز:** نرخ امتیاز، نام و آستانه سطح‌ها، مدت انقضای امتیاز، متن رضایت پیامک تبلیغاتی.

**گیت فاز:** موجودی امتیاز هرگز منفی نشود (قید DB)، محاسبه RFM روی داده نمونه با نتیجه مورد انتظار، خروجی و حذف داده مشتری کار کند.
