# فاز ۴ — میز، رزرو و بیعانه (هفته ۷ تا نیمه ۸)

**هدف:** رزرو آنلاین با ثبت‌نام اجباری، بیعانه قابل روشن/خاموش برای هر شعبه و پیامک.

**پیش‌نیاز:** نقشه سالن‌ها و میزها، سیاست رزرو (مدت، مهلت لغو، حداکثر نفرات)، مبلغ و قانون بازگشت بیعانه، Terminal ID و محیط تست سامان کیش، حساب سرویس پیامک.

**گیت فاز:** تست هم‌زمانی رزرو (دو درخواست هم‌زمان برای یک میز ← فقط یکی موفق)، پرداخت/Verify/Reverse موفق در محیط تست SEP، پیامک در همه وضعیت‌ها.
